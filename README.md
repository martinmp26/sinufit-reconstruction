# SinuFit — Reconstruction

This is a new browser-based prototype inspired by the original SinuFit logo and login screenshot. It is not the recovered original code.

## Features
- Red/black visual identity and responsive login screen.
- Demo login (not real authentication).
- Dashboard navigation.
- Sample routines and exercise lists.
- Editable profile.
- Session completion history and simple progress summaries.
- Browser localStorage for local demo data.

## Run
Open `index.html` in a modern browser, or use VS Code with Live Server.

## Limitations
- No backend or database.
- Login accepts a demo username and any password of at least 4 characters; never use a real password.
- Data remains in this browser/device.
- Routine content is newly written sample content, not verified original SinuFit content.
- All implementation in this project is newly created for the reconstruction.
